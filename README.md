# Ex-002: Project Evaluation & Production Architecture

Welcome to `ex-002`! This project has been evaluated and enhanced with a robust, production-grade TypeScript application structure, testing suite, build system, and continuous integration workflow.

## Features & Architecture
- **Vite + TypeScript**: High-performance frontend development environment and bundler.
- **Vitest & Testing Library**: Comprehensive unit and integration test suites.
- **Tailwind CSS**: Modern styling framework for responsive UI.
- **GitHub Actions CI**: Automated build, test, and typecheck verification on every push and pull request.

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Run test suite:
   ```bash
   npm test
   ```
4. Build for production:
   ```bash
   npm run build
   ```
